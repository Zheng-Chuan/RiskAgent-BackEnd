RiskMonitor MultiAgent 已部署!

提示: 后续部署/升级请使用 -n riskmonitor --create-namespace 标志，namespace 不存在时由 Helm 自动创建（无需独立 namespace 资源）。

=== 验证 ===
kubectl get pods -n {{ .Release.Namespace }}
kubectl get svc -n {{ .Release.Namespace }}

=== 健康检查 ===
kubectl exec -it deploy/{{ .Release.Name }}-mcp-server -n {{ .Release.Namespace }} -- curl http://localhost:8000/health

=== 访问服务 ===
MCP Server: kubectl port-forward svc/{{ .Release.Name }}-mcp-server 8000:8000 -n {{ .Release.Namespace }}
Prometheus:  kubectl port-forward svc/{{ .Release.Name }}-prometheus 9090:9090 -n {{ .Release.Namespace }}
Grafana:     kubectl port-forward svc/{{ .Release.Name }}-grafana 3000:3000 -n {{ .Release.Namespace }}
